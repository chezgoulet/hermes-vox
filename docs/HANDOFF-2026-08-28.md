- **Relay = CLIENT-DIRECT** (the important detail). At session start the client fetches the profile's resolved voice config via **`GET /api/audio/voice-config`** (provider/model/voice/credential), then talks DIRECTLY to the STT/TTS providers (ElevenLabs/OpenAI/Groq/Mistral/DeepInfra/xAI; local whisper/Edge/NeuTTS for LAN-only). - **Offline matrix:** on-device = **no-network offline** (truly offline); client-direct = **local-network offline** (local gateway + local whisper/Edge/NeuTTS + local LLM = no internet, but needs the gateway reachable); cloud STT/TTS = needs internet. ## Key architecture facts (verified — trust these)
- **The entity (memory, skills, context, SOUL) lives in the agent's files + the session, NOT the model.** Changing the inference backend preserves the entity.
- **Blessed model-change for an API client = the per-request `provider`+`model` override on `/v1/responses`** (`_extract_request_runtime_kwargs` → `requested_provider`/`requested_model` → `_run_agent`). The `/v1/responses` path "reconstructs the full conversation from the stored response chain (all tool calls + results preserved)." The app's `/models` chooser sets a `provider`+`model` (per-request override), not a brain swap.
- **`/api/sessions/{id}/model` / SessionDB (`state.db`) is a DIFFERENT surface** (messaging/browser/dashboard sessions). The Vox `/v1/responses` conversation is a response chain, NOT a SessionDB session — do **not** use `POST /api/sessions/{id}/model` or `currentResponseID()` as the session id for Vox. (The full SessionDB session path is a **deferred, larger re-architecture**.)
- **`GET /v1/models` returns only `hermes-agent`** (thin, cheap OpenAI surface). **`GET /api/model/options`** is the real provider/model catalog `{providers:[{slug,name,models[],total_models,is_current,authenticated,source,capabilities,warning}]}` (auth/current badges). `/models` uses this. `GET /v1/health` → `{status,platform,version}`.
- **/v1/responses streaming** = the OpenAI Responses SSE shape Vox's `emitEvents` parses; the session-chat SSE is a different shape.
