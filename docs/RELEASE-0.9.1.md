# Hermes Vox 0.9.1

## Presence
- Presence is a layer, not a mode
- Alpha features gate, off by default
- Small model holds the line; the agent answers
- No more swallowed turns
- VOX.md per profile
- Asides and backchannels
- Resume after an interruption
- Overlap classification
- Presence tuning bar
- Presence transcript
- Continuous capture and semantic endpointing
- First-run hardware check

## Commands and settings
- Commands reworked from the ground up
- Settings regrouped by what you're changing
- Model switcher: provider → category → model
- Every dialog on the app's own ground
- Deep UI refinements for light mode
- Look controls with a live preview

## The call
- Approvals on the phone, by touch or voice
- Silence is never a yes
- Turn budget pauses for approvals
- Voice instructions moved into the API
- Voice turns keep their tools
- Reasoning effort setting for voice
- Speech during a turn is kept, not dropped
- Spoken repair instead of silence
- The agent narrates its own work

## Phone and agent
- Local actions: timer, alarm, do-not-disturb, volume
- The agent can see what the phone is doing
- Profiles come from the host
- Files handed to the agent, not uploaded
- Vox is a share target
- Scrollback through the agent's speech

## Distribution
- sherpa-onnx built from source
- Reproducible builds
- F-Droid metadata prepared

## Not yet
- The agent can't direct or veto phone actions
- Voice, model and look are device-wide
- Upgrade path from 0.9.0.3 untested
