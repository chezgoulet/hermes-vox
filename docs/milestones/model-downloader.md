# Demo Note — In-App Model Downloader + Blessed Defaults (GREEN)

Date: 2026-08-25 · Emulator-5554 (Android 15) · store hosted on Thelio (`100.68.43.34:8899`)

## What shipped
The user can download the on-device models **from inside the app** (no sideload,
no build-time fetch, no cloud keys), with the **blessed path marked as the
default**. Models land in app-private storage (`filesDir/models/<id>/`) and
inference is fully offline.

- `ModelCatalog` — the BLESSED set (with sha256 + explicit "blessed/recommended"
  order):
  - Silero VAD (barge-in/wake) → replaces the RMS hack
  - Piper · en-US (Lessac) TTS (warm on-device voice)
  - Whisper (tiny.en) STT → replaces Google SpeechRecognizer
- `ModelDownloader` — streams a ZIP from the source into app-private storage
  (built-in `HttpURLConnection` + `ZipInputStream` + `MessageDigest`; **no new
  dependency**), verifies the sha256, unpacks. Progress + cancel + error surfacing.
- `ModelsActivity` — blessed storefront: source host field, "Download recommended
  (blessed)", and per-model cards (★ RECOMMENDED badge, size, Not installed /
  Downloading % / ✓ Installed / Error→Retry).
- Settings → "Voice models" row (live "N/3 installed"). Default pipeline = blessed.
- The model **source is user-configurable** — default is the house Thelio model
  store (sovereign/LAN), adjustable to `http://127.0.0.1:8899` for a local backend.
- `scripts/model-store.sh` + `finalize-store.sh` — fetch the blessed set from the
  verified open-source endpoints, repackage as flat ZIPs, write the manifest, serve
  over http. The store is gitignored (regenerated by script).

## Verification (live)
Driven the real UI: Settings → Voice models → set source → download Silero →
**installed**. Ground truth:
```
files/models/silero-vad/silero_vad.onnx   643854 bytes   (exact expected size)
Settings row: "Voice models — 1/3 installed · on-device, offline"
```
The downloader also proved graceful failure: a malformed source produced a clean
`ERROR: FOR INPUT STRING: '8899HTTP:'` + Retry (no crash).

## Constraint found (Android platform)
**Android 9+ blocks cleartext HTTP by default** — the Kotlin downloader
(`HttpURLConnection`) was refused with `CLEARTEXT HTTP TRAFFIC TO 127.0.0.1 NOT
PERMITTED`. (The Go entity connector bypasses this via raw sockets, which is why
the entity worked on plain http.) Fix: a **network security config** permitting
cleartext (correct for a local-first app talking to LAN/tailnet hosts over http).
This also means the model downloads must point at an http source (house store).
