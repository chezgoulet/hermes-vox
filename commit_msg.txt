docs: 0.9.1's goal is the closed loop (D24)

The founder interrogation settled the direction, and it changes 0.9.1 from a list of fixes into a claim with a gate.

**The goal:** command out, visible work, clean feedback, discovery — closed. "Good with Presence off" is a property the release must have, not its purpose.

**The gate (#279):** one stranger completes the calendar run by voice with no tutorial — read the day, decline a meeting, draft, edit a part by voice, send, clear the time, check trail conditions.

Seven issues now carry the loop's work, all in 0.9.1:

- #279 the acceptance run (the gate)
- #280 state audit — which surface carries which state; the being is not assumed to carry them all
- #281 operations — what is running, and on what
- #282 approvals — the sign-off Hermes asks for, answerable by voice or touch, timing out to no
- #283 feedback — what changed, and how to undo it
- #284 discovery — being, interface and search designed as one system
- #285 the app skill — bundled and enabled, so the agent can teach

Failure is defined too: a regression, or an interface that needs explaining, fails the release even if every issue closes.

D24 records the direction, the slice Vox refuses to grow beyond (not a command centre, not a dashboard aggregator, not a second desktop client), the Sesame benchmark for 0.9.2, and the 1.0 bar.

Also updated: the `milestone/0.9.1` and `milestone/1.0` label descriptions, which still described the old framing.

Docs and issue text only; no code, no version bump.
